# Розширена перевірка Mac Compact на COCO128

Дата: 2026-09-07. Мета — перевірка локального captioning на різноманітних сценах та перший smoke пошуку людей і SAM Tiny. Це технічна й вибіркова візуальна перевірка, а не оцінка якості на незалежному benchmark.

Уточнення користувача під час прогону: надалі агент виконує лише технічні перевірки, без порівняння зображень із captions/масками. Наведені нижче якісні знахідки отримано до цього уточнення; нові візуальні перевірки не проводяться. Правило збережено в кореневому `AGENTS.md`.

## Технічний результат captioning

40/40 captions, 0 зареєстрованих помилок, джерела й промпти незмінні. Експортовані image/TXT звірено byte-for-byte. Час на фото 4,13–7,16 с, медіана 5,66 с, сума 227,53 с без встановлення/завантаження моделі. 60–102 нових токени на caption.

Максимум серед snapshot: MPS allocated 3,97 GiB, driver 9,30 GiB. Driver на першому/останньому зразку: 9,12/9,18 GiB. Це точкові заміри, не peak і не доказ відсутності витоків; memory pressure/swap не вимірювалися. Технічні метадані й `benchmark_summary.json` збережено в `captioning_tool/outputs/mac-coco40/`.

## Технічний результат regions/SAM

Перший прогін `people6/` із лімітом 1000 токенів: 5/6 JSON-відповідей розібрано, одна обірвана відповідь (`000000000110.jpg`). SAM 2.1 Tiny на MPS створила 21 PNG-маску для успішних регіонів. Програмно перевірено координати в межах кадру, відповідність розмірів image/mask, бінарні значення 0/255 і непорожність усіх 21 масок. Джерела й промпти незмінні. Процес коректно повернув exit code 1 через помилку регіонів.

Додано `--region-tokens` (default 1000) і явну діагностику досягнення ліміту без EOS; неповна JSON-відповідь зберігається в `grounding_raw/` і не приймається як успішний результат. Для проблемного фото передбачено окремий повтор із 2048 токенами, без перерахунку успішних зразків.

Повтор із 2048 токенами також завершився досягненням ліміту без EOS: 1 помилка, 0 масок, незмінні джерела. Результат збережено в `captioning_tool/outputs/mac-coco-region-retry1/`; проблему не вважаємо вирішеною простим збільшенням ліміту. Потрібна окрема робота над обмеженням довжини/повторів структурованої відповіді або іншим region prompt.

Виправлено залежність стадій: SAM обробляє лише зразки з успішним grounding; невдалий grounding більше не отримує статус завершеної сегментації. Якщо успішних відповідей немає, SAM не завантажується. Для перевірки цього захисту використано негативний тест із `--region-tokens 1` на одному фото.

Loader SAM виводить попередження про `sam2_video` у конфігурації checkpoint при завантаженні через `Sam2Model`. Ваги завантажилися, маски згенеровані; попередження не приховувалося. Це технічний smoke, не повна перевірка архітектурної сумісності чи якості масок. Візуальне порівняння масок не проводилося відповідно до уточнення користувача.

Результат першого прогону: `captioning_tool/outputs/mac-coco-people6/`.

## Датасет

[COCO128 від Ultralytics](https://docs.ultralytics.com/datasets/detect/coco128/) містить 128 фотографій із COCO train2017. Архів 6 983 030 байтів (~6,66 MiB). Походження, checksum, оригінальні README/LICENSE та зображення збережені в `projects/test-datasets/coco128/`, поза Git. Умови використання фото визначаються їхніми початковими ліцензіями; див. [COCO Terms of Use](https://cocodataset.org/#termsofuse). Ліцензія супровідного коду не підміняє ліцензії фотографій.

SHA-256 архіву: `61e5e3028863d8ffc3b81d6a514603954889f0edd5e4b44c4ce60b2da99aeb8e`.

`smoke40/` — 40 фото, відібраних за покриттям категорій YOLO: спочатку нові категорії, потім кількість категорій у кадрі, потім менший ID. Вибірка охоплює 71 ID категорії за наявними labels: люди, транспорт, тварини, їжа, предмети та інтер’єри. 31 горизонтальне й 9 вертикальних фото; ширина 381–640 px, висота 312–640 px. Список файлів у `SOURCE.json`.

Два фото повного архіву (`000000000250.jpg`, `000000000508.jpg`) не мають TXT-розмітки. Це зафіксовано в manifest; їм не приписували категорії. Detection labels використовуються лише для відбору, не як captions або доведена ground truth для цього експерименту. Вибірка не перевіряє ілюстрації, великі кадри чи стабільність identity.

`people6/` — шість вручну вибраних сцен: вершники, скейтпарк, ресторан, дві людини стоячи, вітальня та група на лавці. Вона призначена для візуальної перевірки регіонів/масок, не для вимірювання recall або IoU без ручної розмітки.

## Відтворення

З кореня репозиторію у вже створеному Mac runtime:

```bash
captioning_tool/runtime/mac/bin/python captioning_tool/fetch_coco_test_dataset.py
HF_HUB_OFFLINE=1 ./captioning_tool/auto_captioning_tool.command --input projects/test-datasets/coco128/smoke40 --output captioning_tool/outputs/new-coco40
./captioning_tool/auto_captioning_tool.command --stage regions --input projects/test-datasets/coco128/people6 --output captioning_tool/outputs/new-coco-people6
```

Captioning використовує Qwen3-VL-2B, MPS float16, batch=1, до 320 токенів і `prompts/neutral/general.txt`. Регіони використовують ту саму Qwen та наявний person-oriented prompt; SAM — 2.1 Tiny. Моделі завантажуються послідовно. Offline captioning потребує вже завантаженої Qwen; перший запуск regions може завантажити SAM. Кожен output має бути новим/порожнім.

## Вибіркові знахідки якості captions

Основні об’єкти й тип сцени часто описані правильно, але точні атрибути та взаємодії потребують перегляду:

| Фото | Перевірена проблема |
| --- | --- |
| `000000000049.jpg` | Вигадані сині куртки вершників і стрибок через перешкоду під кіньми |
| `000000000086.jpg` | Припущення, що людина готує або оглядає мотоцикл |
| `000000000113.jpg`, `000000000142.jpg` | Відтворення написів/брендів усупереч вимозі промпту не транскрибувати текст |
| `000000000151.jpg` | Людину, що визирає з транспорту, описано як відображення в дзеркалі |
| `000000000165.jpg` | Чорні леза великих ножиць помилково описано як стрічку на краватці |
| `000000000257.jpg` | Додано конкретну назву пам’ятки, яка не встановлювалася в межах тесту |

Це приклади з вибіркового перегляду, не вичерпний перелік і не частка помилок у датасеті. Відсутність runtime errors не означає, що captions готові для навчання без перевірки. Результати не переписувалися вручну, щоб зберегти чесний baseline. Наступний крок для якості — редактор/затвердження та порівняння промптів або моделей на окремій контрольній частині.
